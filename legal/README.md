## ✅ Что осталось до публикации

### 1. Заполнить реквизиты (15 минут)

Во всех трёх документах есть блоки `[заполнить]`. Это:
- **ИНН** (есть в кабинете ЮMani или в Госуслугах)
- **ОГРНИП** (там же)
- **Юридический адрес** (адрес регистрации)
- **Расчётный счёт + БИК + банк** (из договора с банком)
- **Дата вступления в силу** (рекомендую — дата согласования с юристом)

Где взять реквизиты быстро:
- **Госуслуги** → «Мой бизнес» → ИП → скопировать ИНН/ОГРНИП
- **ЮMani кабинет** → раздел «Контрагент» → все реквизиты
- **Сбербанк/Тинькофф бизнес** → реквизиты счёта

Найдите в текстах документов `[заполнить]` (через cmd+F) и подставьте.

### 2. Прогнать через юриста (1-2 часа работы, ~5-10к ₽)

**Зачем:**
- AI знает типовые шаблоны, но не знает специфику твоего бизнеса
- Юрист проверит соответствие 152-ФЗ, ст.437 ГК РФ (оферта), Закону
  о защите прав потребителей
- Юрист может добавить специфичные пункты под твою деятельность

**Где найти быстро и недорого:**
- **Pravoved.ru** — онлайн-консультация от 1000₽/час
- **YouDo** → «юрист на час»
- **Sberbank Юристы** — пакет «Старт» для ИП ~5000₽
- Знакомый юрист по интернет-праву (лучше всего)

**Что попросить юриста:**
- «Проверь оферту/политику ПДн/соглашение на соответствие законодательству РФ
  для SaaS-сервиса с подпиской через YooKassa»
- «Особое внимание: возвраты денег, обработка изображений клиентов мастера,
  трансграничная передача в OpenAI/Anthropic»
- «Если что — поправь сразу, готов оплатить дополнительно»

### 3. Зарегистрировать как оператора ПДн (30 минут, бесплатно)

**Это обязательно по 152-ФЗ для любого, кто обрабатывает ПДн.**

1. Открой [portal.rkn.gov.ru](https://portal.rkn.gov.ru/)
2. Раздел: «Уведомления об обработке ПДн»
3. Подать новое уведомление
4. Заполнить форму: ИНН, цели обработки (из privacy.md раздел 4),
   категории ПДн (раздел 3), способы обработки (автоматизированный
   через ИИ), сроки хранения
5. Отправить через ЭП или Госуслуги
6. Через 30 дней получишь номер в реестре операторов ПДн
7. Этот номер вписать в privacy.md (раздел 2)

**Без этой регистрации:** Роскомнадзор может оштрафовать до 50 000 ₽ (ст.13.11 КоАП РФ).

### 4. Опубликовать на сайте + бот (10 минут)

После согласования с юристом:

**На сайте ta2tut.ru:**
- Добавить страницы `/oferta`, `/privacy`, `/terms`
- Конвертировать .md → HTML
- Ссылки в футере лендинга

**В боте:**

  [офертой] и [политикой]»
- В Mini App «Кабинет» — раздел «Документы»
- В команде `/help` — пункт «Юридическая информация»

### 5. Тестирование (10 минут)

- Кликнуть все ссылки в боте → открываются нужные документы
- На сайте все три ссылки работают
- При первой регистрации в боте видно соглашение
- Email pishublock@gmail.com принимает письма по теме «Персональные данные»
